# Azure Dreams (PSX) — Traducción al español

Traducción no oficial apoyada con IA (fan-translation) de **Azure Dreams** (PlayStation, versión USA,
SLUS-006.14) al español.

Este repositorio **no incluye ninguna imagen del disco ni archivo del juego**. Solo
contiene:

- `AzureDreams_ES.ppf` — el parche de traducción, en formato **PPF 3.0**.

## Estado de la traducción

- **Texto de diálogos** (`SLUS_006.14`, `MAIN.BIN`, `TOWN.BIN`, `DUNGEON.BIN`,
  enciclopedia de monstruos): traducido.
- **Objetos** (nombres, descripciones, precios): traducido.
- Los acentos y la `ñ` no están en la fuente del juego.
- Nombres de personajes y monstruos: sin traducir.
- Gráficos de menú/interfaz: pendiente.
- Introducción del juego: pendiente de la traducción y creación de subtitulos.
